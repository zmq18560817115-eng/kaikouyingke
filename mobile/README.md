# 开口迎客 · 手机端首期工程

依据《开口迎客 AI 情境普通话训练 App 需求文档 V2.0》、信息架构 PPT 和五张页面图实现。采用 uni-app + Vue 3，一份业务代码输出微信小程序和移动 H5。底部导航按用户确认固定为：首页、课程、AI 游客、复习、我的；“我想说”保留首页入口。

## 现在可以使用

- 五个主页面及情境详情、训练、完成、模拟问答、复盘、个人表达、复习、经营任务、资料和设置等业务视图。
- 欢迎询问、价格购买、特色商品介绍三个情境，共 12 个短课。每章四课逐步覆盖听懂、关键词、跟说、复述、对话和独立挑战。
- 六类游客的固定问法变体，三级提示；复盘后可主动加入复习。
- 用户核对名称、材料、制作、价格和单位后，整理并保存简短版与完整版个人情境卡。不填的经营事实不会自动补齐。
- 本机保存课程进度、断点、个人卡、草稿、复习和接待自评；H5 音频使用 IndexedDB，小程序使用本地保存文件。
- 录音、回听和删除的实际平台实现；首次主动点击后才请求麦克风，离开或转入后台停止采集。模拟接待可在单次明确授权后发送录音进行发音评测。
- 大字模式、主动播放声音、录音隐私管理、内置课程说明。

新安装数据从零开始。截图中的“验收示例商品”和少量学习记录来自浏览器验收操作，不是预置用户资料。

## 运行与编译

使用 Node.js 22 或更新版本。首次运行：

```sh
npm ci
npm run speech:prepare
npm run dev
```

本机预览：<http://127.0.0.1:5174/>。手机通过局域网访问 H5 时，浏览器麦克风通常要求 HTTPS；本机 localhost 可用于开发。

```sh
npm test
npm run build:h5
npm run build:mp-weixin
# H5 生产运行（先完成 build:h5）
PORT=3000 npm start
```

- H5 产物：`dist/build/h5`，需要 HTTP 服务，不能双击 HTML 离线运行。
- 微信产物：`dist/build/mp-weixin`。在微信开发者工具中导入此目录；编译器提供游客模式配置 `touristappid`。真机预览和发布需要项目自己的 AppID，在 `src/manifest.json` 的 `mp-weixin.appid` 填写后重新编译。
- Android/iOS 原生安装包没有打包。本工程保留 uni-app App 端配置；原生包需要 HBuilderX、应用标识、签名和设备验证。当前可验收的输出为 H5 与微信小程序工程。[官方 CLI 说明](https://uniapp.dcloud.net.cn/quickstart-cli.html)

## 工程结构

| 位置 | 职责 |
| --- | --- |
| `src/data/library.js` | 本地课程、六阶训练定义、游客问法、复习分类及来源说明 |
| `src/pages/index/index.vue` | 主导航与业务视图栈；当前采用单原生页中的业务视图切换 |
| `src/components` | 图标、返回标题、分区标题 |
| `src/styles.css` | 颜色、字号、卡片、按钮、布局、小屏及大字规范 |

| `src/store.js` | 响应式状态与本机持久保存 |
| `src/services/audio.js` | 平台录音、播放、文件和浏览器音频存储 |
| `src/static` | 压缩插画及 Phosphor 图标 |

首次打开进入特色商品情境，与参考首页一致；也可在课程中选择欢迎或价格情境。餐饮制作介绍可使用共用表达课程与自己的事实卡。住宿、路线、文化等内容包明确显示尚未开放。

## 实现边界

当前是可运行、可继续开发的首期客户端，不是已经上线的完整 AI 服务。模拟接待使用课程固定问答；手动完成明确记录为自报练习，不给机器分数或“已经掌握”结论。

模拟接待的普通话自由讲述评测接口、录音上传和评分展示已实现，但尚未开通腾讯云服务或配置真实凭据，当前不能获得真实评分。自由追问、母语转写、地区母语示范、账号云同步、内容审核后台仍需实际服务和审核内容。四句接待用语、关键词及三句课程跟说已有内置普通话合成示范与慢速版；其他句子的声音取决于设备语音包。内置插画仅辅助学习，不能证明商品材料、制作、价格或文化事实。

免费本机反馈默认可用；网页版可按需下载 SenseVoice 模型进行文字核对，不需要腾讯凭据。`services/api.js` 提供可选的同源专业语音评测接口。供应商密钥仅在服务端配置；没有真实凭据时明确提示“发音打分尚未开通”。开通步骤、接口、分数来源和有限试用边界见 [接入说明](integration/README.md)。

小程序安装后，内置文字与图片可离线使用；H5 没有 Service Worker，首次加载和重新打开依赖开发服务或已部署站点。本地数据不会跨设备同步，清除应用/站点数据会丢失记录。

## 已验证与待验证

H5 已实际走通：五个主入口、课程答题及断点续学、完成后刷新保留、个人事实卡生成及重开、角色和高级提示切换、三轮接待复盘、加入复习并完成、设置和 360/390/412 宽度。控制台未发现错误。领域规则测试及两个目标的编译均通过。

未代替用户授予麦克风权限，实际采音、设备语音质量、来电/蓝牙切换及录音删除须真机验收。微信开发者工具的本机 UI 检查停在系统辅助功能/屏幕录制权限环节；不能将编译成功等同于微信模拟器或真机测试通过。系统字号 200%、屏幕阅读器和目标年龄用户测试仍待验证。

## 0.2.0 讲述发音评分

模拟接待录音结束后新增“讲述发音打分”：同意上传后显示发音准确度、流利度、识别文本和优先练习字词。复盘可逐条评分并显示已评分回答的平均准确度，结果与原录音一起保存在本机，删除录音时一起删除。

当前尚未开通评测服务，正式页面会显示待开通；不展示模拟分数。先按接入说明开通腾讯云并在 Railway 配置服务端变量，再完成真实录音验收。

## 0.3.0 免费本机语音练习

首页和 AI 游客页新增四句接待用语跟读。16段原文各有普通话合成示范与慢速版，共32个小体积音频，内置于 H5 和微信包。录音结束后提供本机能量停顿反馈；网页版在用户主动确认后下载约240MiB的 sherpa-onnx / SenseVoice 包，真实本机推理后才计算跟读完整度和估算语速。录音不上传；文字匹配不代表发音准确度。自由回答不按范文计算完整度。可对比同一句最近两次练习、定位回听停顿、在设置中清理模型缓存。

先执行 `npm run speech:prepare` 下载并验证固定版本模型；失败不影响停顿与回听。Docker 构建会自动准备模型，小程序构建不复制大包。浏览器不支持或内存不足时明确降级，小程序尚未接入本地文字识别，原生安装包未打包。模型分发仍会消耗网站流量，不等于托管全免费。完整方案及验证边界见 [独立应用方案](../交付/开口迎客_免费语音练习应用方案_V0.3.md)。

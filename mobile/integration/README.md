# 在线 AI 接入边界

此目录说明下一阶段接口，不代表已经提供服务。当前客户端的课程学习、固定问答和本机记录不调用外部 AI。

## 用户授权与数据

用户每次录音后先保存在本机。在线分析必须在明确的用途说明与授权后上传，并提供撤回和删除入口。服务端使用真实用户身份和访问控制，个人音频与课程默认私有。不能把设备本地标识作为正式认证。

## 建议接口

| 接口 | 输入与行为 |
| --- | --- |
| `POST /v1/attempts` | 音频、课程/问题 ID、事实版本、提示级别、客户端 attempt ID；返回任务 ID；相同 attempt ID 幂等 |
| `GET /v1/attempts/:id` | 返回上传、排队、分析、完成或失败状态；完成必须附证据来源 |
| `POST /v1/personal-cards/prepare` | 用户明确核对的事实；返回草稿和缺失事实，不自动猜价格、材料、工艺或文化结论 |
| `POST /v1/personal-cards/:id/confirm` | 用户确认草稿；服务端保留事实版本和审核状态 |
| `DELETE /v1/recordings/:id` | 身份校验、对应对象删除、任务引用与删除状态处理 |
| `GET /v1/content-manifest` | 已审核课程/音频包版本、地区语言、大小、校验和 |

## 评测结果要求

结果应区分音质不足、转写不确定、信息遗漏、影响理解的发音、独立完成程度。只有足够证据时才展示明确建议；展示原音回听及至多一个优先改进点。自报完成不转换成模型评价。

服务端需根据 ASR 的不确定性和真实游客理解目标评测，不能以消除民族口音为目的。文化、宗教、历史和健康相关内容进入当地专业审核，未审核内容不自动发布到公共课程。

配置真实供应商后，先在预发布环境验证拒绝授权、静音、噪声、短录音、网络超时、重复请求、权限撤回与删除。凭据只保存在服务端环境或密钥管理系统中。

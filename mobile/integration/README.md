# 普通话自由讲述发音评测 · 0.2.0

模拟接待已增加录音后的评分入口、单次上传授权、结果展示、字词提示、回顾页逐条评分与已评分回答的准确度平均值。供应商调用代码使用腾讯云「口语评测（新版）」普通话自由说（`eval_mode=3`）与录音识别模式（`rec_mode=1`），不要求用户照读范文。

**当前没有开通评测服务或配置真实凭据，不能返回真实分数。** 未配置时前后端都明确提示待开通，不上传音频、不返回演示分数。自动测试中的供应商响应仅为测试夹具，不会用于正式站点。

## 开通步骤

1. 在腾讯云开通[口语评测（新版）](https://cloud.tencent.com/document/product/1774/107497)，由账号所有者完成账号、协议及额度选择。
2. 在 Railway 的 `kaikouyingke` / `production` 服务 Variables 中填写下列服务端变量。不要把密钥发送到聊天、写进仓库或放进 `VITE_` 变量。
3. 变量更新后重新部署服务。`GET /api/speech/capabilities` 应返回 `enabled: true`；此状态只表示配置齐全，仍需实际录音联调确认凭据、服务开通和额度可用。
4. 在模拟接待中录制 2–59 秒普通话，点击“发音打分”，明确同意本次上传后查看结果。

| 服务端变量 | 值 |
| --- | --- |
| `SPEECH_ASSESSMENT_ENABLED` | `true`，没有开通前保持 `false` |
| `TENCENT_SOE_APP_ID` | 腾讯云 AppID |
| `TENCENT_SECRET_ID` | 有语音评测权限的 SecretId |
| `TENCENT_SECRET_KEY` | 对应 SecretKey |
| `SPEECH_DAILY_LIMIT` | 可选，默认每进程每日 100 次；范围 1–1000 |
| `SPEECH_ALLOWED_ORIGINS` | 可选，准确前端来源，以逗号分隔；同源部署无需填写 |

示例变量见 `mobile/.env.example`。本地可复制为 `mobile/.env`（Git 与 Docker 均忽略）后运行 `npm run dev:api` 和 `npm run dev`；Vite 将 `/api/speech` 转发至本机 5176。

## 当前接口

- `GET /api/speech/capabilities`：配置状态、语言、时长上限；启用时签发短时上传令牌，不暴露供应商密钥。
- `POST /api/speech/assess`：JSON `{format, audio, duration, consent:true}`；audio 为 Base64，header 带 `X-Assessment-Token`。H5 将真实录音解码为单声道 16kHz/16bit WAV；微信录音使用 MP3。
- 只有供应商终结标记与最终有效结果齐全，才返回准确度、流利度、识别文本、字词分数、优先建议、供应商请求 ID 和时间。

主分数直接使用供应商 `PronAccuracy`（0–100），流利度将 `PronFluency` 从 0–1 转为百分制。自由讲述不提供编造的内容完整度或语法分。复盘平均分是已评分回答准确度的算术平均值，明确显示参与数量；未录音和未评分回答不计入。

## 数据与访问边界

原录音保存在本机，只有每次明确同意后才上传至本站并转发腾讯云。本站不将音频写入磁盘、数据库或日志，短期结果缓存最多十分钟；供应商按其数据政策处理音频。本机删除会删除原录音及其本机评分记录，不声称能删除供应商侧数据。录音已有但服务不可用时仍能回听和手动完成。

当前适合有限试用：短时来源绑定令牌、同源校验、3MB 请求上限、2MB 音频上限、2 并发、来源每日20次、全进程每日额度和录音内容幂等缓存。配额按北京时间日期重置，进程重启会重置计数，多副本之间不共享；这些不替代正式账号鉴权和持久化账务限制。正式大规模上线前需接入用户身份、共享配额及真实供应商监控。

## 验证边界

自动测试覆盖签名、录音模式、最终结果归一化、无有效分数拒绝、静音/格式/时长、取消/超时、来源校验、授权令牌、未配置服务和重复请求。接口联调使用模拟 WebSocket 响应。真实腾讯云凭据、实际录音质量、供应商错误、设备转换和费用尚未实测；不能把测试通过写成真实语音评分已开通。

协议与字段依据：[新版接口](https://cloud.tencent.com/document/product/1774/107497)、[评测结果数据结构](https://cloud.tencent.com/document/api/884/19320)。自由追问、地区母语音频、云端账号与学习同步仍未接入。

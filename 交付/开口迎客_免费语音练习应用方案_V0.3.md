# 开口迎客 · 免费语音练习应用方案 V0.3

交付日期：2026-10-18。适用现有 uni-app / Vue 3 项目，H5 部署到现有 Railway 服务。

## 产品行为

首页「先练一句接待用语」及 AI 游客页「先练一句，再开始接待」进入免费跟读。首批四句：欢迎光临、您想看哪一种、这件产品是手工制作的、我给您介绍一下。每句含普通话合成示范、慢速示范、关键词音频及预设读法提示。示范为开源 MeloTTS 合成音，尚未替代真人教学校审；没有使用付费合成接口。

流程：听示范 → 关键词慢读 → 录音 → 回听 / 本机停顿反馈 → 按需下载文字识别包 → 核对跟读完整度、估算语速 → 再练同一句并对比。

课程「短句跟说」按课程原句核对；看图复述、独立挑战及模拟接待属于自由表达，不要求复述范文，不计算文本完整度。模拟接待与复盘同样可以查看本机反馈，专业腾讯评测收在「更多」中，仍须单次授权上传。

## 三项反馈的定义

| 反馈 | 数据来源与计算 | 显示边界 |
| --- | --- | --- |
| 跟读完整度 | 本机真实识别文字与固定练习句进行字符级、保序编辑对齐；准确匹配的原句字符数 / 原句总字符数 | 仅跟读显示百分比；未识别、无声、自由表达均不显示完整度；文本吻合不代表发音准确 |
| 语速 | 识别字数 / 首尾有声片段之间的跨度 × 60 | 标点不计，数字和拉丁字母参与字符计数；有声跨度不足1秒不估算；不把更快视为更好 |
| 较长停顿 | 20ms 帧 RMS 能量分段，合并小于180ms的间隔，过滤短于160ms的片段，记录内部至少600ms的低能量间隔 | 首尾等待时间不计；背景音、距离与设备会影响估计；点击位置从停顿前0.4秒开始回听 |

本地能量分析不是专业声学 VAD，也不输出声母、韵母、声调、音素准确度或普通话等级。没有统一合成「发音总分」。未匹配文字标为「建议回听」，不据此断定漏读或读错。预设发音提示来自课程内容，不根据录音自动诊断。

同一句最近两次练习比较文字完整度的百分点变化、停顿数量及语速变化；两次都没有文字结果时，不生成完整度差值。练习录音和报告同存在本机，删除录音同时删除其报告；不改变课时掌握判定。

## 本机识别架构

录音文件 → Web Audio 解码、单声道16kHz → RMS 停顿分析 → Web Worker 中的 sherpa-onnx / SenseVoiceSmall 推理 → 字符对齐与报告 → IndexedDB / 本机学习记录。

H5 使用 sherpa-onnx v1.12.9 官方 WASM 包与 `sherpa-onnx-sense-voice-zh-en-ja-ko-yue-int8-2024-07-17`，固定中文语言。官方压缩包约158 MiB，浏览器需加载文件共251,888,664字节（约240 MiB）；首次由用户主动确认下载，界面显示百分比、失败重试、取消和缓存状态。下载文件逐一验证 SHA-256，在 Cache Storage 中保存；校验完成后从已验证的字节启动 Worker。用户录音只传入本机 Worker，不通过网络请求上传。

识别没有按次 API 调用费。仍有既有网站托管、首次模型分发流量、设备存储和计算成本。模型加载本身需较多内存，低内存手机可能失败；失败时保留回听及已有的停顿反馈。缓存可能被浏览器清理；缓存不等于整个 H5 站点已经具备离线启动能力。

## 平台边界

| 平台 | 当前状态 |
| --- | --- |
| 移动 H5 / 支持 WASM 的现代浏览器 | 完整的示范、录音、停顿、按需文字识别、完整度及语速；需要 HTTPS 或 localhost，受内存及存储限制 |
| 微信小程序 | 合成示范文件内置，录音、回听；有 WebAudio 解码能力时提供能量反馈；不加载网页版 WASM 大包，文字识别未接入 |
| Android / iOS 原生安装包 | 未打包、未真机验收；需单独对接 sherpa-onnx 原生插件，不声称 H5 Worker 已等同原生接入 |

微信端保留明确的能力不足提示，不回退到未告知的云端识别。没有使用可能把录音发送至第三方的浏览器默认 SpeechRecognition。

## 运行、构建和部署

在 `mobile` 目录：

```sh
npm ci
npm run speech:prepare
npm run dev
# 验证 / 发布构建
npm test
npm run build:h5
npm run build:mp-weixin
```

`speech:prepare` 从 sherpa-onnx 官方 GitHub v1.12.9 下载固定压缩包并校验压缩包 SHA-256 `7f5ef4cec861cc6da6fbd98e8b4732e986aacd082604d41503700e325a4e4fdb`。生成的模型与 WASM 位于 `public/speech/runtime-v1.12.9`，由 Git 忽略；Docker 构建阶段自动准备，编译 H5 时复制进入产物。微信构建不复制 `public` 大包。

已有 Railway 服务继续使用 `mobile/Dockerfile`，不需要腾讯凭据、不需要新建模型推理服务器。模型由本站作为静态文件分发，推理在用户浏览器中完成。服务器支持音频 Range 请求、正确的 AAC/WAV/WASM MIME 和固定版本模型缓存。

没有准备模型包时，界面会说明文字识别暂不可用，停顿和回听仍可使用。没有腾讯凭据时，专业发音评测仍明确待开通。

## 已验证与待验证

30项自动测试覆盖静音、噪声提示、停顿首尾排除、短间隔合并、保序跟读比对、重复字、自由表达不评分、无真实识别时不出文字分、缓存重算、删除关联，以及已有腾讯接口与数据规则。静态服务测试覆盖音频 Range。

在实际内置浏览器中，完整加载 WASM 与模型，并对内置合成示范音频进行了真实推理，三句返回「欢迎光临」「这件产品是手工制作的」「我给您介绍一下」。这属于真实模型推理验收，测试输入是合成音，不代表目标经营者口音、手机性能或复杂背景音已通过验收。H5、微信编译通过，微信产物约1.8MB，未包含模型大包。

尚需用户实际麦克风、不同手机浏览器、微信真机、方言口音、慢速停顿、网络中断、存储不足与长期缓存清理测试；没有替用户授予麦克风权限。

## 系统逻辑架构

```mermaid
flowchart TB
  subgraph Client[用户训练端]
    UI[首页 课程 AI游客 复习 我的]

  end
  subgraph Service[业务服务]

    Learning[课程 会话 能力证据 复习 真实任务]

    API --> Personal
    API --> Sync
  end
  subgraph AI[受控AI任务执行]
    Quality[音频质量与识别置信]

  Local <--> API
  Personal --> AI

```

## 学习闭环

```mermaid
flowchart LR
  Goal[真实接待目标] --> Listen[听懂情境]
  Listen --> Words[关键词]
  Words --> Repeat[短句跟说]
  Repeat --> Retell[看图复述]
  Retell --> Dialogue[AI游客对话]
  Dialogue --> Challenge[独立挑战]
  Challenge --> Task[真实经营任务]
  Task --> Reflection[事后自评与新问题]
  Reflection --> Review[个性化复习]
  Review --> Goal
  Hint[提示 L2完整示范 L1关键词 L0情境目标] -.-> Repeat
  Hint -.-> Retell
  Hint -.-> Dialogue
  Hint -.-> Challenge

```

## 录音评价状态

```mermaid
stateDiagram-v2
  [*] --> ready
  ready --> recording: 用户开始且已授权
  recording --> recorded: 用户结束
  recording --> interrupted: 来电或切后台
  interrupted --> recorded: 保留片段并确认
  recorded --> upload_pending: 离线且有上传同意
  recorded --> analyzing: 在线提交
  upload_pending --> analyzing: 联网且同意仍有效
  analyzing --> quality_retry: 质量不足或识别不确定
  analyzing --> feedback: 可评价且证据有效
  quality_retry --> ready: 回听或重录
  feedback --> ready: 再试一次
  feedback --> [*]: 保存并继续
```

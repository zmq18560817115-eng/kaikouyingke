# 讲述发音评分交互规范

对应客户端 0.2.0。模拟接待中的自由回答可以录音后逐条评测，不要求照读标准范文，不推断商品事实是否正确。

## 操作路径

模拟接待 → 开始回答 → 结束录音 → 发音打分 → 同意本次上传 → 上传与评测 → 查看结果。三轮结束后的接待复盘保留每条回答的报告，并按已评分回答显示发音准确度平均值与参与数量。

## 报告

沿用奶白底、白色圆角卡片、绿色主色和现有中文字体。主数字为发音准确度 /100，辅项为流利度 /100；两项均来自供应商结果，不根据录音时长或文本相似度猜测。展示识别讲述、需优先练习字词的琥珀色标记、一条优先改进建议、来源与回听入口。

## 状态

- 没有录音：提示先录下本次回答。
- 评测未开通：明确提示尚未开通；不提供上传令牌、不上传录音、不显示分数。
- 授权：每次提交前单独说明腾讯云接收音频、本站临时处理和本机结果保存，由用户选择同意或取消。
- 整理/上传/评测：显示处理中与取消等待入口，阻止重复提交同一操作。
- 静音、短录音、格式不支持：提示重新录制，原录音与学习进度保留。
- 超时、服务中断或额度不足：显示明确原因与重试入口，不降级为虚构分数。
- 结果：持久保存在本机，复盘和录音管理中可再次查看；删除本机录音时一起删除本机报告。

## 当前边界

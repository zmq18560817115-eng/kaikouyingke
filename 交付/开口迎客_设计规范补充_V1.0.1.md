# 开口迎客设计规范补充 V1.0.1

对应客户端 0.1.1，2026-10-16。沿用独立设计规范 V1.0 的颜色、插画、字体、卡片与五项导航。

1. AI 游客页主行动固定在底部导航上方，显示“当前情境 · 当前难度”，按钮为“开始模拟接待”。固定区随大字模式增长，内容末尾留足滚动空间。
2. 录音区增加“正在打开”“正在保存”状态。保存期间阻止重复录音和下一步；离开页面前等待已开始的保存结束。
3. 保存失败应明确提示并保留原页面和输入，不能显示成功、增加进度或跳到完成页面。
4. 草稿转换成个人情境卡后，从草稿列表移除；重复保存同一草稿更新已有条目。
5. H5 内容页说明网页需要联网打开；小程序基础文字与图片可离线。所有学习数据与录音仍仅保存在本机。

截图与操作证据见 `mobile/design-qa.md`。设备音频、系统辅助功能和目标用户验证仍待完成。

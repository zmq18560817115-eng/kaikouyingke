# 开口迎客设计规范

V1.0  2026年10月14日

本规范用于开口迎客手机小程序和App界面设计、组件实现及验收。应用以35至60岁家庭式旅游经营者为主要用户，采用语音优先、图片辅助、文字补充的交互方式。设计保留原始五张页面中的雪山草地插画、绿色动作按钮、浅色卡片和固定底部导航。

本规范同时包含首期已实现规范和后续 AI、云端能力接入后的目标状态；后续能力不代表当前已上线。首期实现边界见第 07 章。这是独立的设计规范，侧重视觉、布局、组件、页面、交互状态与可访问性。系统服务、接口和数据库架构另见架构文档。手机应用工程位于mobile目录，五个固定入口为首页、课程、AI游客、复习、我的。首页固定保留我想说。

## 设计目标

让经营者快速找到今天要练什么，听清并自己说一遍，明确接下来做什么。一次只突出一个主要动作。反馈围绕游客是否理解信息，不对用户的口音、文化或个人能力作标签化评价。

| 视觉来源 | 使用原则 |
| --- | --- |
| 首页及课程原图 | 保留风景和学习卡层级，进度用实际记录计算 |
| AI游客原图 | 保留角色插画和难度选择，小屏允许两列 |
| 复习原图 | 保留今日推荐与分类，数量来自实际队列 |
| 我的原图 | 保留能力和管理层级，课时不等同能力掌握 |
| 补充页面 | 复用同一组件，不增加无关装饰语言 |

## 阅读顺序

第01至02章定义视觉与组件，第03至04章定义主页面与训练页面，第05至06章定义状态恢复与可访问性，第07章定义素材和设计开发对照。

# 01 视觉基础规范

## 保留与收敛

保留雪山草地的柔和插画和绿色行动按钮，主要用于五个一级页面的情境氛围。训练页面压缩风景占比，突出问题、播放和录音。装饰图不承载唯一信息，不能使用户误以为雪山图代表所有地区。公开发布前确认原插画与人物素材的使用权。

| 语义Token | 色值 | 用途 |
| --- | --- | --- |
| color.brand.primary | #237A59 | 主按钮、选中状态、关键进度 |
| color.brand.pressed | #195F44 | 主按钮按下状态 |
| color.text.primary | #102B24 | 标题、正文主信息 |
| color.text.secondary | #58665F | 辅助说明，禁止低透明度灰字 |
| color.surface.canvas | #FAF8F3 | 暖白背景 |
| color.surface.card | #FFFFFF | 内容卡片 |
| color.surface.green | #EDF6E8 | 正向状态浅底 |
| color.surface.blue | #E6F3FB | 听力与信息浅底 |
| color.surface.amber | #FFF2D5 | 待加强与注意浅底 |
| color.feedback.warning | #9A5B00 | 警示文字，必须搭配说明 |
| color.feedback.error | #B23B35 | 权限或系统问题，避免用于口音评价 |
| color.border.control | #7B8C83 | 输入边界、未选中的可操作轮廓 |

品牌绿上的白字按WCAG公式约为5.3比1，主文字对白色约为15.1比1，辅助字对白色约为6.0比1。实际验收须覆盖插画背景、遮罩及各状态，不能仅以Token合格推断整页合格。轻分隔线不承担控件识别功能。

## 字体与间距

优先系统中文无衬线字体，普通话为主、母语语音为辅助。以移动端逻辑像素为基准，小程序按设备实际宽度适配，不从853像素宽截图直接推导字号。首页标题32至33、训练标题25、卡片标题21至26、正文18至20、辅助15至16、底部导航13至14。正文行高1.5至1.8。大字模式正文22、辅助18，布局随内容增高。间距使用4、8、12、16、24、32dp。

# 02 布局与组件规范

## 页面网格

以390dp宽为主要设计基准，同时验收360、390、412dp及大字号。左右边距16dp，卡片内边距16至20dp，卡片间距12至16dp。一级页风景区建议210至218dp，内容自然滚动，底部导航独立固定并加系统安全区。次级与训练页风景区控制在72至120dp。

| 组件 | 尺寸与样式 | 状态和交互 |
| --- | --- | --- |
| 主按钮 | 高54至64dp，圆角28dp，文字21至22 | 默认、按下、加载、不可用，点击目标至少48dp |
| 次按钮 | 高54至56dp，绿色轮廓或浅底 | 用于重听、稍后与辅助行动 |
| 内容卡片 | 圆角20dp，内边距16至20dp | 全卡可点时有语义名称，避免内部动作冲突 |
| 录音控制 | 主触区72dp以上，图标加“点击开始说” | 点击开始、点击结束，取消独立操作 |
| 播放控制 | 最小触区48dp，正文说明播放对象 | 同时只播放一个音源，录音时停止示范 |
| 难度选择 | 三段可点区，每段至少48dp高 | 颜色、边框与文字共同表达选中 |
| 游客卡片 | 390dp时2列，角色名20sp可换行 | 选中边框加标记，不只改变底色 |
| 信息行 | 单行最小64dp，说明换行则自增高 | 右侧箭头仅表示可进入 |
| 进度条 | 8dp高，标签说明2/4课 | 不用能力百分比替代真实证据 |
| 状态标签 | 正文可读，文字加图形 | 下载、待分析、待审核等明确命名 |

截图中三列游客与五列课程卡在小屏容易缩小文字，新版优先改为两列游客与两列课程卡，保留插画配色和卡片语言。首页三个快捷入口可保持三列，但最窄单元保留48dp触区，文字过长时改成纵向列表。

## 动效与图像

状态切换建议150至250毫秒，减少动态效果时关闭装饰动画。图片等比裁切、人物脸部及商品信息保留安全区，不能拉伸插画。头像来自用户选择或授权素材，不根据民族和性别自动套用人物。后台列表优先清晰文本与版本信息。

# 03 五个一级页面设计规定

| 页面 | 内容顺序 | 主动作与修正规则 |
| --- | --- | --- |
| 首页 H01 | 问候、今日练习卡、三快捷入口、真实任务 | 主按钮“继续练习”；明确“第3课，共4课”，不写含混2/4 |
| 课程 C01 | 总进度、当前情境、公共情境、职业包 | 当前卡“继续学习”；其余卡为入口，不同屏争夺主动作 |
| AI游客 A01 | 标题、角色、当前情境、难度、开始 | 默认推荐角色，允许不逐项设置直接开始；在线状态清楚 |
| 复习 R01 | 今日队列、加强点、分类、记录新问题 | “开始复习”；分类计数标为总待练，与今日队列区分 |
| 我的 M01 | 用户资料、能力、累计学习数据、管理 | 编辑资料用次按钮；能力基于证据，默认私人可见 |

## 首页的具体变化

沿用图片首页顶部景色和主练习卡。主卡固定展示情境、具体短课、剩余练习及预计时长。快捷入口依次为模拟接待、我想说、复习，整个卡片可点击。真实任务可进入记录，不能只做装饰性横幅。没有进度时主卡显示“开始第一课”，没有真实任务时展示接待后的问题记录入口。

## 课程页面的状态

未开始展示任务目标，进行中显示准确课次，已学显示“可以再练”，扩展包标为“后续开放”并解释原因，不显示伪可点按钮。下载状态独立于学习状态。已下载课程在断网时照常进入，无下载的课程提供下载说明和返回已有课程。

## AI游客与复习

角色名称与需求文档保持一致，“没听懂的游客”可用换行，不截成难理解的词。初级完整提示、中级图片和关键词、高级默认无答案。高级主动求助后仍允许完成，但记录实际提示。复习空态显示“今天已完成”，提供可选的已学情境重练，不制造待练数量。

## 我的与隐私表述

将“所有学习记录仅自己可见”改为“默认仅自己可见，协助与审核按授权范围开放”，并提供可查看的授权列表。累计数据从实际练习事件计算。首期仅保存本地记录；云同步接入后再显示同步状态。

# 04 补齐页面的设计规定

## 训练页 C04至C09

顶部返回、课名和六关当前位置，随后是“这次要说清什么”、情境图或问题、示范与辅助操作，底部放唯一主要动作。已给完整答案的跟说页与无答案独立挑战必须有明显提示区别。录音后原位显示反馈，已说清的信息放前面，再展示一个改进点和“再说一次”。

## 对话与复盘 A02至A03

对话顶部显示角色、当前任务、问题1/3和退出。问题区包含播放与“慢一点”，回答区显示正在听或已保存。求助收在固定次按钮内，展开后依次给提示。结束页不以大分数作为主视觉，先展示游客已了解、仍缺的信息，再给一个“练习这个问题”的主按钮和真实任务入口。

## 输入与事实确认 S01至S05

S01以“想向游客介绍什么”为标题，录音主入口，拍照和记录问题为次入口。S03每次重点确认一项，提供回听、正确和重说，文本编辑为补充。生成中显示正在处理的阶段，不展示虚假的百分比。S05默认播放简短版，完整版可切换，明确AI整理、本人确认及审核状态。

## 真实任务 H02至H03

任务说明具体到一个可完成的行为，提供“稍后记录”。反馈页五种自评使用大点击行，用户选中后才出现“保存结果”主按钮。选择新问题后可直接口述，不要求输入游客身份。没有机会接待时允许跳过，保留原学习进度。

## 离线与录音管理 M05至M07

每个包显示名称、地区语言、版本、大小、完成度和状态。删除下载包说明不影响学习记录。录音列表区分本地与云端副本，删除前用一段短说明讲清范围。点击删除后先显示执行状态，失败保留重试，撤回同意后停止对应上传。

## 能力地图 M02

以“我能做什么”列出欢迎、报价、介绍和应答，附上在帮助下完成、独立完成待验证、已验证等证据标签。点击可回听本人保留的录音，或直接重练。无录音保留时仍显示不含原声的能力记录，不能出现空白音频按钮。

# 05 状态与恢复规范

| 状态 | 用户文案示例 | 动作及数据规则 |
| --- | --- | --- |
| 初次无记录 | 从当前经营情境开始，约5至6分钟 | 开始第一课，保留跳过评估 |
| 无复习项目 | 今天的复习已完成 | 自选重练，无虚构数量 |
| 首次录音授权 | 需要麦克风来练习，可随时关闭 | 用户点击后请求系统权限 |
| 拒绝麦克风 | 还不能录音，可以先听示范 | 去设置为次动作，不阻断听课 |
| 正在录音 | 正在听，点击结束 | 持续计时，后台中断自动停止 |
| 噪声或静音 | 这次声音不够清楚，换个位置再试 | 试听、重录，不生成低分 |
| 识别不确定 | 我还不能确定这句话，请听听录音 | 回听、重说、请求协助 |
| 分析超时 | 正在分析，录音已保存 | 稍后查看，不重复上传 |
| 断网 | 已保存，可以先练已下载内容 | 保留草稿，展示待联网分析 |
| 生成缺事实 | 还需要确认价格和单位 | 回到对应事实项，不瞎补 |
| 待审核 | 这段地方知识需要核对后再练 | 编辑素材、查看进度 |
| 下载失败 | 更新没有完成，仍可用已下载版本 | 重试或继续旧版 |
| 空间不足 | 手机空间不足，请先管理下载内容 | 提供管理，保留个人草稿 |
| 删除中 | 本地已删除，云端正在处理 | 查看状态，失败可重试 |
| 保存冲突 | 另一台手机也修改了这张情境卡 | 对比并保留选择，不静默覆盖 |

## 录音状态机

idle、permission_required、ready、recording、interrupted、recorded、upload_pending、analyzing、feedback、quality_retry。停止录音后才能上传。取消录音清理尚未确认的片段；已确认录音的删除单独执行。任何重试都保留attempt_id与幂等键，重新录制才创建新的尝试。

## 页面通用规则

加载时有操作名称，长任务允许离开。全屏错误只用于页面完全不可用，其余在相关卡片原位恢复。弹窗仅用于范围明确且后果重要的操作，正文说明影响，不用“确定吗”代替说明。Android返回键与页面返回一致，未保存录音提供保存草稿或放弃选项。

# 06 可访问性与语音交互

## 触控与字号

所有交互区域至少48乘48dp，主要按钮56dp以上，相邻触区保留8dp间隔。正文采用大字号并支持系统字号放大，按200%字号进行重点页面验证，不能让按钮文字被固定高度裁切。短标签可换行，页面自然增高并滚动，不能靠整体缩小解决溢出。

## 颜色与背景

普通文字目标对比度至少4.5比1，大字至少3比1；关键控件边界、状态和图形目标至少3比1。文字叠插画时使用稳定的纯色或遮罩区域，抽查最差背景。已选、错误、待分析同时提供文字或形状，不只依赖绿、红、黄区分。

## 辅助技术

为TalkBack标注控件名、角色、值和状态，例如“播放游客问题，按钮，未播放”。焦点顺序跟随视觉阅读顺序。装饰性山景不朗读，商品及情境图使用与练习目标相符的描述，独立挑战的描述不能泄露完整答案。错误出现后播报简短消息并把焦点放到可恢复位置。

## 声音优先但不强制

示范、母语解释、游客问题与用户录音共享音频协调器，同时只播放一个音源。录音开始自动停止播放，结束后由用户主动回听。提供外放与耳机模式、慢速、重复和分句。语音提示可关闭并有等价文字，不自动大声朗读私人内容。关键事实确认可用声音完成，不强制键盘或拼音。

## 地区与环境验证

辅助语言名称、样音与实际地区匹配由当地人员核对。验证嘈杂经营场所、外放回声、来电、权限撤回、蓝牙切换、弱网及低存储。操作反馈避免“你的口音太重”“发音不标准”，使用“金额还没听清”“再试一次这个词”。

## 依据

Android官方无障碍建议作为触控和语义实现参考。WCAG2.2作为视觉可访问性验收参考，本版不构成已取得合规认证的声明。来源链接见第07章，具体实现仍需真机和辅助技术验证。

# 07 素材规范与设计开发对照

## 插画素材

山水背景、欢迎接待、商品与六类游客插画沿用原图的柔和绘本风格，作为独立素材使用，不能把整张页面截图作为应用界面。源码assets目录保留原尺寸PNG，应用static/images目录使用压缩JPEG。人物和商品按比例显示，禁止拉伸；重要主体保留安全区。图标来自Phosphor官方图标库，保持同一线条风格。

| 素材类别 | 建议应用位置 | 处理规则 |
| --- | --- | --- |
| landscape | 五个一级页面顶部 | 适度裁切风景，标题放在平稳天空区 |
| product | 课程与任务卡、练习情境 | 白底完整显示，不当作实际商品事实证明 |
| welcome | 欢迎情境与首页快捷卡 | 避免遮挡人物脸部 |
| tourist系列 | AI游客角色卡 | 人物上半身保持清楚，选中有边框和标记 |
| Phosphor图标 | 导航、录音、播放、管理入口 | 使用统一色值和尺寸，不用字符代替图标 |

## 当前工程与设计对照

首期已实现本地课程、固定角色问答、录音保存与回听、事实核对、模板表达卡、复习和经营任务记录。在线 AI 评测、地区母语音频、人工审核和云同步仍需接入服务，相关状态为后续设计目标。浏览器首次加载需要网络或本机开发服务；完整离线文字与图片能力以已安装小程序为准。应用的学习流程包含五个一级页面、情境详情、六关练习容器、单课完成、固定情境对话、复盘、我想说、事实确认、个人课程、复习队列、真实任务、资料、离线、录音与设置。页面视觉与源参考相同，数据由实际本机记录驱动。未接通真实AI评价时，不显示机器打分或掌握结论。

| 设计检查 | 验收方式 |
| --- | --- |
| 导航与主要按钮 | 五个入口固定，当前选中明确，主要流程可完成 |
| 图片与文字 | 无缺图、拉伸、文字裁切，弱网已有内容可读 |
| 表单与字号 | 长内容可换行，大字模式不盖住按钮 |
| 录音与状态 | 主动采集，结束保存，权限失败可恢复，离开停止 |
| 学习与能力 | 有效练习才记录进度，不伪造AI评价或真人验证 |
